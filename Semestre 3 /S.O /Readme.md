# 💻 Sistemas Operacionais I (SO I)

Repositório dedicado aos estudos, atividades práticas, anotações e projetos da disciplina de **Sistemas Operacionais I**, ministrada pelo **Prof. Deivison** no 3º semestre do curso de **Análise e Desenvolvimento de Sistemas (ADS)**.

---

## 📌 Visão Geral da Disciplina

O objetivo desta disciplina é compreender o funcionamento interno, a arquitetura e os conceitos fundamentais dos sistemas operacionais modernos, além de dominar o uso de ambientes de linha de comando (CLI) e gerenciamento de recursos do sistema.

* **Curso:** Análise e Desenvolvimento de Sistemas
* **Semestre:** 3º Semestre
* **Professor:** Deivison
